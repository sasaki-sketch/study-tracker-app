# AnkiノートタイプのCSS更新手順

## 🎯 問題

修正版カードは追加されましたが、**CSSファイルがAnkiに反映されていない**ため、色付きテキストが表示されていません。

## 📝 解決方法: 手動でCSSを更新

### ステップ1: CSSをコピー

以下のコマンドを実行して、改善版CSSをクリップボードにコピーしてください:

```bash
cat /Users/sasaki/IMPROVED_ANKI_CSS.css | pbcopy
```

または、ファイル `/Users/sasaki/IMPROVED_ANKI_CSS.css` をテキストエディタで開いて、全内容をコピー (Cmd+A → Cmd+C)

---

### ステップ2: Ankiでノートタイプを編集

1. **Ankiを起動**

2. **メニューバー** → **ツール** → **ノートタイプを管理** (または `Cmd+Shift+N`)

3. **ノートタイプ一覧から選択**:
   - `Greek Letters v2 (Super Readable)` を選択

4. **「カード」ボタンをクリック**

5. **「スタイル」タブを開く**

6. **既存のCSSを全削除** (Cmd+A で全選択 → Delete)

7. **新しいCSSを貼り付け** (Cmd+V)

8. **「保存」をクリック**

9. **ウィンドウを閉じる**

---

### ステップ3: 確認

1. Ankiブラウザを開く (`Cmd+B`)

2. 検索: `deck:"Greek Letters & Statistics" tag:variables`

3. カード「説明変数と目的変数の違いは?」を開く

4. **確認ポイント**:
   - ✅ 「目的変数(Y)」が**赤色**で表示される
   - ✅ 「説明変数(X)」が**青色**で表示される
   - ✅ すべてのテキストが読みやすい

---

## 🔧 トラブルシューティング

### 問題1: ノートタイプが見つからない

**原因**: ノートタイプ名が違う可能性

**解決**:
- ノートタイプ一覧で `Greek` で始まるものを探す
- または `Basic` や他のノートタイプを使用している場合は、そちらを選択

### 問題2: CSSを貼り付けても反映されない

**原因**: Ankiのキャッシュ

**解決**:
1. Ankiを完全に終了
2. 再起動
3. カードを再度確認

### 問題3: 色がまだ表示されない

**原因**: カードのHTMLにCSSクラスが設定されていない

**解決**:
- 古いカードが残っている可能性
- Ankiブラウザで `tag:variables` で検索
- カードが5枚のみであることを確認（重複していないか）
- もし重複していたら、古いカード（色が表示されないもの）を削除

---

## 📋 CSSが正しく適用されたかの確認方法

Ankiブラウザで以下のカードを開いて確認:

1. **変数カード1**: 「説明変数と目的変数の違いは?」
   - 「Xで説明する側」→ **青色**
   - 「Yを予測する目的」→ **赤色**

2. **変数カード5**: 「Y = 2 + 3X で、係数3の意味は?」
   - 「2」→ **グレー**
   - 「3」→ **赤色**
   - 「説明変数(X)の影響力」→ **青色**

3. **変化率カード2**: 「変化率の分子・分母は?」
   - 「10万円」→ **赤色**
   - 「50万円」→ **青色**
