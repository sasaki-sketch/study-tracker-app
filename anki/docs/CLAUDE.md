# Anki統計検定2級カード改善プロジェクト

## プロジェクト目標
精度の高いAnkiカードで統計検定2級に合格する。
「何回もこなしたい」カードを作成する。

## 決定事項

### 技術選定
- **数式**: MathJax（LaTeX記法）
  - 理由: Anki標準対応、PC/モバイル両対応、美しい表示
  - 色分けは不使用（モバイル表示問題のため）
- **グラフ**: matplotlib
  - 枚数: 5-10枚のみ（必要最小限）
  - 日本語フォント設定必須
  - Base64エンコードでHTML埋め込み
- **対応環境**: PC（Mac）+ モバイル（iOS/Android）両対応

### 既存カード方針
- **削除対象**: 既存44枚すべて
  - averages_simple.py (7枚)
  - distributions_simple.py (10枚)
  - shape_measures_simple.py (6枚)
  - inequality_simple.py (7枚)
  - math_formulas_simple.py (8枚)
  - powers_of_two_simple.py (6枚)
- **理由**: ゼロから精度の高いカードを作成

### 品質方針
- **精度 > 枚数**
- 不確実な情報は含めない
- 検証できない内容は保留
- 1枚のカード作成に時間をかけても良い

### 説明スタイル
- **公式**: 簡潔な定義のみ
- **具体例**: 1つ（検算済み）
- **微分積分**: 統計検定2級に必要な最小限のみ
- **ギリシャ文字**: 新基準で作り直し

## カード作成プロセス

### 1. 情報収集（WebSearch + Fetch）
信頼できる情報源:
- 統計検定公式サイト
- 統計WEB（統計学習サイト）
- 大学の統計学教材
- 公式問題集・参考書

### 2. 情報の検証
- 複数ソースでの整合性確認
- 公式定義と一般的な説明の照合
- 計算例の妥当性確認

### 3. カード作成
テンプレートに従って作成（下記参照）

### 4. 講師視点でのレビュー
チェック項目:
- [ ] 数式・公式は正確か
- [ ] 定義に誤りはないか
- [ ] 説明は明確で誤解を招かないか
- [ ] 例題の計算は正しいか
- [ ] 統計検定2級の範囲・難易度に適切か
- [ ] 重要な注意点が含まれているか
- [ ] 出典が明記されているか

## MathJax（LaTeX）記法例

```latex
# 分数
\[\frac{1}{2}\]

# 総和
\[\sum_{i=1}^{n} x_i\]

# 平方根
\[\sqrt{x}\]

# 指数
\[e^{x}\]

# 積分
\[\int e^x dx = e^x + C\]

# 対数
\[\log_{2} n\]
```

## 気になった点（19項目）

### 数式表現の問題
1. 分数が見づらい（1/2など）
2. 指数がわかりにくい（e^xなど）
3. 総和記号が表現できない（Σ）
4. 積分記号が表現できない（∫）

### 問いと答えの不一致
5. 「いつ使うか」を聞いているのに「公式」を答えている
6. 「覚え方」を聞いているのに「定義」を答えている

### 説明不足
7. 公式だけで使い方がわからない
8. 計算例がない
9. 注意点が書かれていない

### グラフ・図の不足
10. ローレンツ曲線のグラフがない
11. ヒストグラムの例がない
12. 幹葉図の視覚的説明がない

### 計算の複雑さ
13. ジニ係数の計算手順が複雑すぎる
14. 台形公式の説明が不十分

### 内容の正確性
15. カード4の計算例に誤りがある可能性
16. 一般的な値の範囲が曖昧

### 構成の問題
17. 1枚のカードに情報が多すぎる
18. 逆に情報が少なすぎるカードもある

### 出典の不足
19. 情報源が明記されていない

## 改善要望（5項目）

1. **公式はテキストではなく美しい数式で表示**
   - 実装: MathJax（LaTeX記法）

2. **グラフや図を含める**
   - 実装: matplotlib（5-10枚のみ）

3. **問いと答えを一致させる**
   - 実装: カード設計時に確認

4. **具体例と計算手順を含める**
   - 実装: テンプレートに「具体例」セクション

5. **出典を明記**
   - 実装: カード下部に出典セクション
